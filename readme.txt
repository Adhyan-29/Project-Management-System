Authentication Backend System:

A secure and scalable authentication system built with modern backend technologies.
This project handles user registration, login, authentication, and authorization using token-based security.

Features:
1.User Registration & Login
2.JWT-based Authentication
3.Password Hashing (bcrypt)
4.Protected Routes (Authorization Middleware)
5.Access & Refresh Token System
6.Logout Functionality
7.Input Validation (express-validator)
8.Error Handling Middleware
